# Data Sources & Provenance

All data sources are official, public, and reproducible. No ad-hoc HTTP requests.

## Debian Package Data

### Binary Package Descriptions
- **URL**: `http://deb.debian.org/debian/dists/sid/{component}/binary-amd64/Packages.xz`
- **Components**: `main`, `contrib`, `non-free`, `non-free-firmware`
- **Format**: Debian binary Packages file (RFC 822 style, ~10MB compressed per component)
- **Contains**: Binary package names, versions, descriptions (~77k binary packages total)
- **Fetched by**: `fetch_data.py` — downloads and stream-parses Package: + Description: fields
- **Stored in**: `data/packages_raw.json` as `description` field per source package
- **Mapping**: Binary package names → source package names via display_name resolution
- **Coverage**: ~99.7% of source packages (41,300/41,437)
- **Cached in**: `~/.cache/orphan/` (see Caching section below)

### UDD (Ultimate Debian Database)
- **Host**: `udd-mirror.debian.net` (public read-only mirror)
- **Database**: `udd`
- **Tables used**: `sources`, `upload_history`, `bugs`, `popcon_src`, `vcswatch`
- **Access**: PostgreSQL with `udd-mirror`/`udd-mirror` credentials
- **Fetched by**: `fetch_data.py` via `psql` COPY command
- **Note**: UDD's `descriptions` table is empty on this mirror — descriptions come from binary Packages.xz instead

## Version Comparison Sources

### Arch Linux
- **URL**: `https://mirror.rackspace.com/archlinux/extra/os/x86_64/extra.db.tar.gz`
- **Also**: `core.db.tar.gz`
- **Fetched by**: `comparisons/arch.py`
- **Stored in**: `data/arch_versions.json`

### FreeBSD Ports
- **URL**: `https://download.freebsd.org/ports/amd64/packages-14RELEASE/INDEX-14.xz`
- **Fetched by**: `comparisons/freebsd.py`
- **Stored in**: `data/freebsd_versions.json`

### Homebrew
- **URL**: `https://formulae.brew.sh/api/formula.json`
- **Fetched by**: `comparisons/homebrew.py`
- **Stored in**: `data/homebrew_versions.json`

### pkgsrc (NetBSD)
- **URL**: `https://ftp.NetBSD.org/pub/pkgsrc/current/pkgsrc/INDEX-10.html`
- **Fetched by**: `comparisons/pkgsrc.py`
- **Stored in**: `data/pkgsrc_versions.json`

### Repology
- **API**: `https://repology.org/api/v1/project/{name}` (per-project)
- **Search**: `https://repology.org/api/v1/projects/?search={name}` (fuzzy)
- **Information**: `https://repology.org/project/{name}/information` (homepage cross-check)
- **User-Agent**: `debian-neglect-explorer/1.0` (identifies as required by Repology ToS)
- **Rate limit**: 1 request/second (per Repology API terms)
- **Fetched by**: `comparisons/repology.py`
- **Stored in**: `data/repology_versions.json`
- **Note**: Re-entrant — caches both hits and misses to avoid re-querying

## Caching

Raw downloaded files and comparison caches are stored separately:

### `~/.cache/orphan/` (downloaded mirror files)
- **What**: Packages.xz files from `deb.debian.org`
- **Files**: `sid_{component}_binary-amd64_Packages.xz` (one per component)
- **Size**: ~11MB total (main ~10MB, contrib ~60KB, non-free ~130KB, non-free-firmware ~11KB)
- **TTL**: 24 hours (re-downloaded if stale)
- **Used by**: `fetch_data.py` — `_fetch_or_cached()` handles download and caching
- **Purpose**: Avoid re-downloading ~10MB compressed files on every run

### `data/` (version comparison caches)
- **What**: Pre-fetched version data from upstream sources
- **Files**:
  - `arch_versions.json` — Arch Linux package versions (~15k packages)
  - `freebsd_versions.json` — FreeBSD Ports package versions (~38k packages)
  - `homebrew_versions.json` — Homebrew formula versions (~8.5k packages)
  - `pkgsrc_versions.json` — pkgsrc/NetBSD package versions (~20k packages)
  - `repology_versions.json` — Repology per-project versions (~11k packages, re-entrant)
- **TTL**: No automatic expiry — re-fetched manually via `python -m comparisons.fetch_all`
- **Used by**: `comparisons/*.py` — each source has `fetch()` and `load_cache()` methods
- **Note**: `repology_versions.json` is re-entrant — saves every 50 queries and skips already-cached packages on resume. Use `--no-resume` to wipe and start fresh.

## Output

- **`data/packages.json`**: Final precomputed data for the frontend
- **`data/packages_raw.json`**: Raw UDD + binary Packages.xz data (intermediate)
- **Schema**: Documented in `schema.json`
- **Generated by**: `build.py`
